# GreenLeaf Frontend Simple Version

This is a beginner-friendly frontend prototype for the GreenLeaf retail inventory system.

It uses only:

- HTML
- CSS
- JavaScript

No React, no Node.js, no phpMyAdmin, and no database are required for this simple version.

## How to Run

1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose `Open with Live Server` if you have the Live Server extension.
4. Or just double-click `index.html` from the folder to open it in Chrome.

## What It Does

- Shows dashboard totals
- Shows product list
- Adds new products
- Records sales
- Reduces stock automatically
- Shows low-stock alerts
- Restocks products
