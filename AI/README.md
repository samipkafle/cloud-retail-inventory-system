# AI and Smart Restocking Module

This folder contains the development work for the project's two core innovations:

1. Smart Restocking Forecast
2. AI-Powered Demand Insights Engine

## Smart Restocking Forecast

The forecast will analyse recent sales data, including 14-day sales velocity, and current inventory levels to support reorder recommendations.

## AI Demand Insights Engine

The demand insights engine will analyse historical sales data to identify product demand patterns and produce:

- predicted demand
- Rising / Stable / Falling trends
- high-demand product rankings
- weekly, monthly and seasonal insights
